# React MERN app

## before start

- add env

```bash
VITE_DB_URL="your DB URL here"
```

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/BrownEdgar/book-store-front.git

```

📦 Install Dependencies and run

```bash
npm install
npm run dev
```

📦 Build for Production

```bash
npm run build
npm run preview
```

📜 Scripts

| Command           | Description                   |
| ----------------- | ----------------------------- |
| `npm run dev`     | Start Vite development server |
| `npm run build`   | Build static production files |
| `npm run preview` | Preview the production build  |
